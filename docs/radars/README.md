# Radars (P3 scaffold)

Thin scanners first — success = actionable owned items, not dashboard pages.

| Radar | Cadence | Minimal output | Anti-gaming |
|-------|---------|----------------|-------------|
| Architecture | Weekly | Diff hotspots / ADR gaps / debt tags | ≥1 owned ticket |
| Technical | Weekly | composer+npm audit / EOL list | High CVE has SLA state |
| Product | Monthly | Usage/sunset candidates (schema if no data) | Evidence column required |
| Governance Health | Weekly | Broken links / stale `last_reviewed` / Constitution pin | Open issue on break |
| Engineering KPI | Monthly | Evidence quality, premature-closure intercepts, regression reoccurrence | Ban CI pass rate / close count as primary KPI |

Scripts may be added under `scripts/radars/` later; this README is the contract.
