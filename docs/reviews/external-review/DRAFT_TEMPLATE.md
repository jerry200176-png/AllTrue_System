### Confidence Score 定義

| 分 | 意義 |
|----|------|
| 5 | 事實清楚，只差社群戰經確認邊界 |
| 4 | 主要事實有來源；推論少數 |
| 3 | 事實／推論參半；假設影響結論 |
| 2 | 多數為推論；證據薄 |
| 1 | 幾乎是假設；本不應發（應先補研） |
| 0 |  evidenceless — **禁止** Ready to post |
