## Learning Funnel

```
Candidate → Research → Reject → Draft → Publish
  → Community Response → Accepted Insight → Implemented → Measured Product Impact
```

| 階段 | 定義 |
|------|------|
| Candidate | 高學習／討論／決策價值議題（含 Opportunity，非僅 Unknown） |
| Research | Quality Gate 研究完成 |
| Reject | 低質或無交流價值（健康訊號） |
| Draft | Discussion Draft |
| Publish | 對外發佈 |
| Community Response | 有可用社群回覆（非純噪音） |
| Accepted Insight | 採納洞見（可明確寫「不採納＋理由」） |
| Implemented | 流程／產品／架構／Agent 規則變更落地 |
| Measured Product Impact | 可指認成效或認知修正證據 |

## ERS 生命週期（Draft 後）

`draft` → `ready` → `posted` → `replied` → `insight_accepted` → `implemented` → `measured` → `retired`／`abandoned`

## D1–D5（輔助，各 0–2）

| 維度 | 含義 |
|------|------|
| D1 | 議題品質（值得交流，非灌水） |
| D2 | 社群信號（新觀點 vs 噪音） |
| D3 | 洞見採納清晰度 |
| D4 | 實作落地 |
| D5 | 實測／認知修正 |
