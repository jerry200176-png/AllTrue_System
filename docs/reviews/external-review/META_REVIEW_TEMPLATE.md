# Meta Review — 連續兩輪零 Draft 之後

> **觸發**：連續兩輪 New Draft = 0（見 SCORECARD）。  
> **目的**：檢查「沒問」是成熟、過保守，還是盲點 — **不是**為了硬產出 Draft。  
> 結論写在 `rounds/YYYY-MM-DD-meta-after-round-N.md`，並回寫 SCORECARD。

| 欄位 | 內容 |
|------|------|
| 觸發輪次 | Round N 與 N−1 皆零 Draft |
| 零 Draft 碼 | （兩輪的 Z 碼） |
| 日期 | YYYY-MM-DD |

## 三問判定

| 假設 | 證據（支持） | 證據（反對） | 判定（是／否／不足） |
|------|--------------|--------------|---------------------|
| A. 系統真的成熟 | Registry closed 穩定；復發↓；無新 epic 邊界 | 仍有高頻 F 族復發／stranded 未解 | |
| B. Research Gate 過於保守 | 多個候選有真實未知但被 Reject；Confidence 門檻攔截合理題 | Reject 皆有充分外部答案；Draft 品質門檻未誤殺 | |
| C. Blind Spot 導致漏題 | Blind Spot 反复同一條；邊界未掃（テスト／需求／Prompt） | Blind Spot 有緩解且下輪可驗證 | |

## 結論（擇一主因，可附次因）

- [ ] A 成熟 — 維持不發問；繼續開發  
- [ ] B Gate 過保守 — 具體放寬哪一條研究／Confidence 規則（寫清楚；仍禁止 KPI 硬凑 Draft）  
- [ ] C Blind Spot — 下輪強制加掃的邊界清單  
- [ ] 混合／證據不足 — 維持現狀並指定下輪要補的證據  

## 明確不做

- 不因 Meta Review 自動產生 Draft  
- 不因此提前建立 Decision Journal／Knowledge Base
