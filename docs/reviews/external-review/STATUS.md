## Next External Intelligence trigger（natural only）

Do **not** open a session until one of:

1. Important Feature / Architecture / UX / Product / Workflow delivery completes → User or Agent asks “worth discussing?”
2. Clear gap vs a mature product (Stripe, Linear, GitHub, Vercel, Supabase, …) with a learning question
3. Design worth sharing / challenging (not because blocked)
4. Human Publish decision on Draft 01 (unblocks Learning Funnel evidence)

---

## Success criteria（redefined）

Success is **not** more Rejects, Drafts, or posts.

Success is:

1. Agent proactively surfaces high-value discussion topics  
2. Community contributes insights research alone did not yield  
3. Accepted insights improve product / architecture / workflow after verification  
4. Agent updates beliefs — not only confirms priors  
5. EI is daily engineering habit — not a time-boxed governance experiment  

---

## Anti-patterns（still forbidden）

- Second parallel process  
- Rolling back Phase 1 evidence  
- Inventing Drafts for KPI / funnel completeness  
- Treating Unknown/Blocker as the only trigger  
- Introducing Decision Journal / Knowledge Base without new evidence + user approval
