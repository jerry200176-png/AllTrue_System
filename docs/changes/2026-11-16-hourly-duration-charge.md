# 未開單的小時計費課程同步更新時數與費用
<!-- release-notes: staff_update=staff-2026-11-16-hourly-duration-charge -->

堂數制、小時計費的課程，在尚未開單、收款或上課時，修改每堂時長、購買堂數或重存計價表單，會依已儲存的排課規劃同步更新總時數，再沿用既有計價更新費用。例如每小時 1,200、1 堂改成 2 小時，費用為 2,400。每週不同時長沿用續課的實際規劃計算；原有整小時捨入仍保留，未處理 #4991 B3 的小數時數模型。

這項修正不批次改資料，不重寫已有帳單（含作廢歷史）、繳費回報或上課／扣堂紀錄，不改月結、共用方案或手動逐堂排課。保留既有單堂手動金額差額的計算。正式個案尚需透過已授權的操作核對，不因程式修正就宣稱原課程已改正。

Refs #5379。R3；無 migration、權限或部署規則修改。復原為 revert 本 PR 的 squash commit，走既有發布流程；人員已保存的課程編輯不會因程式回滾自動撤銷。
