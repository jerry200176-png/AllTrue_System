# 帳單旁直接查收款與收據
<!-- release-notes: staff_update=staff-2026-11-16-bill-receipt-lookup -->

帳務中心的帳單清單增加「收款與收據」，在同一工作視圖展開該學生／課程的帳單及各筆關聯收款，直接開啟已確認入帳的收據，不必先切到收款紀錄重新搜尋。一張帳單的多筆收款各自保留收據入口；待核對、撤銷或未連結收據的紀錄會說明原因。

「查收款與收據」可依姓名找已結清或暫停學生的歷史資料；原本待收清單的暫停學生排除條件不變。舊制無帳單的收據仍可查，不捏造帳單關聯。不改任何金額、收款狀態、入帳／作廢操作或校區權限；查看文件後保留查找條件。切換校區或回報範圍會關閉先前開啟的收據，避免保留舊畫面。

查收據不會自動載入每張帳單的上課日與備註；需要時仍可展開。已收標籤改用既有可讀文字色，修正明暗模式的對比問題。

Refs #4148。這不等於完成該 issue 的帳務規則／歷史資料核對；無 migration 或資料修復。回滾使用一般 revert PR 與既有 deploy，不撤銷任何人員操作。
