## 2026-10-28 — feat(ui): 行事曆／課務對話框與帳務畫面改用共用送出鈕與三態全選（#4488 items 1-2 後續）

- `AtSubmitButton` 新增「父層持有送出狀態」模式（`:pending` + `@click`）：行事曆的請假、調課、代課、加課，課務的調課、搬移堂次、批次請假、新增一堂、月繳續期、提前結束／撤銷調整、購買堂數、批次續報，以及課程編輯的補請假／代課／調課／儲存，送出中都改成轉圈＋處理中文字、按鈕寬度不跳、送出中不能重按（含 Enter 送出）。
