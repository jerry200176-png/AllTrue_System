## 2026-10-21 — fix(courses): 加堂只叫「續課」
<!-- release-notes: staff_update=staff-2026-10-21-inapp-429-one-name-for-renewal -->

- in-app #429 / GitHub #4331：同一件事（同一門課再買一期堂數）在畫面上有「加購堂數／續報加購／續約／加購／去加購／續課」多種名字，主任分不清要走哪條路。
- 依 Founder 2026-10-15 Q8=A，課程列、⋯ 選單、學生管理課程卡、「新增課程」時的既有課程提示、續課視窗按鈕（「確認續課」）、提醒文字與伺服器訊息一律稱「續課」（`frontend/src/lib/courseIntent.js`）；`courseRenewalWording.test.js` 防止「加購」字樣再出現。
- 新增課程仍只有一條路：學生管理「新增課程」；若學生已有進行中課程，沿用既有提示讓主任選「續課」或另建課程。換科目／老師／時段仍在課程列 ⋯ →「轉課」。
- 不修改任何 API、計費或權限；月結「結算 / 續約下月」與試聽「轉為正式課程」名稱不變。
