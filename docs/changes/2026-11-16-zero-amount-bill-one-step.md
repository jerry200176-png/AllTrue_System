## 2026-11-16 — fix(billing): 「0 元卻標成已繳」的帳單可以自己處理（帳務中心重整 第 1 步）
<!-- release-notes: staff_update=staff-2026-11-16-zero-amount-bill -->
- 以前有人把收款登記成 0 元時，系統會留下一張「0 元、已繳」的帳單。0 元不算收到錢，所以合約一直顯示「需核對」；這張帳單兩種作廢都按不了，那筆 0 元收款又被收在「已退回／已撤銷」裡面，主任沒有路可走。正式資料裡有 80 張這種帳單。
- 現在學生帳務的「要先處理」會直接列出「這張帳單是 0 元，卻標成已繳」，並給按鈕「撤銷 0 元收款」。撤銷後那張 0 元帳單會一起作廢，合約回到「未繳」，就可以照實際金額登記收款。
- 沒有收款紀錄的 0 元已繳帳單，可以直接在「帳單」按「作廢」。
- 有標「免費／贈送」或「全額折扣」的 0 元帳單不受影響。系統不會自動改任何一筆資料，都是主任按了才動，並留下原因與紀錄。
