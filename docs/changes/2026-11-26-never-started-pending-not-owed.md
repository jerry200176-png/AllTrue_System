## 2026-11-26 — 整期沒上課的已結案月結課程不再列為待收
<!-- release-notes: staff_update=staff-2026-11-26-never-started-pending-not-owed -->

- 已結案、標為「待核對」的月結課程，如果從頭到尾沒有上過課（堂次全部取消）、沒有開過帳單、也沒有登記過收款，帳務中心不再把它列為待收。
- 之前名單會顯示要收合約金額，但按「登記收款」時系統算出這一期是 0 元而擋下，兩邊對不起來（in-app #599）。
- 只要有一張有效帳單、一筆待確認或已確認的收款，或任何一堂不是「取消」的堂次（已上、已排、請假），規則不變。堂數制課程不受影響。不改任何資料。
