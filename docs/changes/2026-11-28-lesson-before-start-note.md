## 2026-11-28 — fix(billing): 合約開始日前的課，不再顯示登記不了的按鈕，改說明原因與做法 (in-app #607)
<!-- release-notes: staff_update=staff-2026-11-28-lesson-before-start-note -->
- 現象：月結課在合約開始日之前上過一堂，畫面顯示「還沒開帳單」和「登記這筆」，按了卻被擋。
- 原因：月結帳單只算合約起訖日之間的課，開始日前的課登記不到。
- 修正：合約其他月份都已處理、只剩這種課時，畫面不再出現「登記這筆」，改顯示是哪幾堂，以及做法：先看第一張帳單的金額是否已含（已含就不用處理）；沒含、而且確實屬於這份合約，才把合約開始日往前改再登記；不確定就回報。
- 不擋其他月份的收款。沒有改任何金額、帳單或計費規則。（取代原本「併入第一個月」的做法，Founder 2026-11-28 改選小改。）
