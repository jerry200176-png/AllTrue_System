# 已付款課程的日期／時間調整入口
<!-- release-notes: staff_update=staff-2026-11-16-paid-course-schedule-entry -->

「合約／堂次調整」新增單堂日期／時間入口，帶到既有堂次清單；已確認收款、使用自動排課的堂數制課程，另可選「更改之後固定時段」。固定時段表單只顯示星期與開始時間，每堂時長沿用原設定；請求只帶既有排課欄位，不重送單價、堂數、付款或合約日期。原有更正堂數、續課與帳務守衛保留。同步第一列開始時間，避免固定時段已更新但頂層時間仍是舊值。

使用既有課程更新與單堂調課 API；保留衝堂診斷、已點名／已核准與真正單堂例外，不新增權限或自動更動正式個案。月結、手動逐堂排課、僅舊 Paid 旗標的課程不新增固定時段捷徑；仍可沿用各自既有流程。Refs #5390、#5391（in-app #561、#562）；Founder 已確認只改日期／時間，堂數與金額不變。

回滾為 revert 本 PR 的 squash commit 並走既有發布流程；已由人員完成的調課不會自動撤銷。正式站僅驗證導覽與欄位，不代替回報者修改課表或填寫驗收。
