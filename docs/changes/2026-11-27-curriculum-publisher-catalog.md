## 2026-11-27 — feat(exams): 教材範本可從出版社目錄帶入 (#4970)

- 新增教材範本時，科目是數學、年級是七到九年級，會多一個「從出版社目錄帶入」選單（翰林、康軒、南一，上下學期共 18 份）。選了就填好名稱、出版社、單元；一節一個單元，章名放在備註。照原本的儲存流程存檔，沒有新的 API 或資料表。
- 目錄是程式裡的參考資料（`frontend/src/lib/curriculumCatalog.js`），加科目只要加資料列。段考對應不自動填。翰林七下第五、六章沒有可靠的小節來源，先整章當一個單元。
