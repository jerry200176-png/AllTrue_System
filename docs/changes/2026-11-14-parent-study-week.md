## 2026-11-14 — feat(study-tasks): 家長入口可以看孩子這週的讀書任務 (issue 5269 step 4)
<!-- release-notes: staff_update=staff-2026-11-14-parent-study-week -->
- 家長入口的「學習」分頁新增「讀書任務」：家長可以唯讀查看自己孩子在老師安排的讀書計畫裡這週（週一到週日）的任務，依日期分組，每項顯示類別（預習、作業、複習、訂正、其他）、預計分鐘數與是否已完成，並可切換上一週或下一週。家長不能新增、修改或打勾；備註欄是老師端內部文字，不會給家長看；建立者與打勾者的姓名也不會出現。家長端只讀取該登入孩子本人的資料（沿用家長入口既有的登入與授權），任何一位綁定的家長都能看，換孩子時會跟著換。該週沒有任務時顯示「這一週老師還沒有安排讀書任務」。新增唯讀 API `GET /api/v1/parent/study-tasks`，沒有資料表或欄位變更。
