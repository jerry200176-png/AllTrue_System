## 2026-10-28 — feat(ui): 按鈕完成回饋與全選聯動（#4488 第 1、2 項）
<!-- release-notes: staff_update=staff-2026-10-28-ui-feedback-select -->
- 新增共用送出按鈕 `AtSubmitButton`：處理中顯示轉圈並防止重複送出，伺服器確認成功後才短暫顯示「已儲存」，失敗顯示「未儲存」且保留輸入；按鈕寬度不跳動，支援減少動態效果。已用在個人資料（基本資料、教學設定、通知偏好）、科目設定（儲存、刪除）與點名「全部到班」。
- 新增共用三態全選 `AtSelectAll` + `useSelection`：部分選取顯示半勾，旁邊顯示「已選 N 筆」；只選畫面上看得到、可選的項目，篩選或資料更新後自動移除看不到的勾選。已用在點名待點名清單與學習評量批次審核。
- 學習評量批次審核原本「全選」會選到被科目篩選隱藏的評量，且切換篩選後舊勾選仍會被送出；現在只會送出畫面上的勾選。
- 點名「全部到班」部分失敗時，未成功的堂次保持勾選，可直接再送一次。
