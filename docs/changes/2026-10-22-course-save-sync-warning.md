## 2026-10-22 — 課程設定改繳費方式後，不再誤報「部分堂次未同步」
<!-- release-notes: staff_update=staff-2026-10-22-course-save-sync-warning -->

- 課程設定儲存時（例如堂數制改月結，in-app #406）會重送原本的固定時段。堂次早已在原時段、不需搬動時，後端把「0 筆搬動」當成「堂次被狀態鎖住」，回傳 `session_sync.warning`，畫面跳「部分堂次未同步」（Refs #4435、#4099）。
- 現在只在這次儲存真的改了固定時段（星期／時間／時長），而且有「尚未開始、但因狀態（已點名、試聽、請假待審等）無法搬動」的堂次留在新固定時段之外時才提示，並寫出筆數；時段沒變的儲存（例如只改繳費方式）不再提示。
- 改時段時，若有請假待審的堂次留在舊時段，即使其他堂次已搬動也會提示（之前只在 0 筆搬動時提示）。
