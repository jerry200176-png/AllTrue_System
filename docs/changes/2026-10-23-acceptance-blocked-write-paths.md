## 2026-10-23 — Production acceptance names the HTTP write its read-only guard blocked
<!-- release-notes: silent_ship=silent-2026-10-23-acceptance-blocked-write-paths -->
<!-- silent-reason: CI/ops log line only; no product change -->

Since #4450 the log shows a flaky first attempt failing at the `afterEach` expectation `read-only acceptance must not send HTTP writes to any origin`, but not which write the guard aborted. `acceptance-report-gate.mjs` now reads that failure's expect() diff in the Playwright report (the spec and the guard are untouched) and prints each unexpected blocked write under the attempt's `failed-attempt` line as `blocked-write attempt=N METHOD host /path`: only the method, origin host and path are taken, the query string, body, headers and every other part of the error text are dropped, and each path segment that is not a plain lowercase route word or `vN` becomes `:id` (repeats get ` xN`, at most ten are printed). A write the gate cannot rebuild safely is counted as `withheld=N`, never echoed. The verdict is unchanged: a flaky test still fails the run. The gate self-test feeds Playwright's real error text (colour codes included) and checks that ids, query values, CJK text and unrelated failures never reach the log.
