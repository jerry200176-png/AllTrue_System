- 合約卡片抬頭：「繳費日 yyyy/mm/dd　NT$ x」取最近一筆已確認收據（與列印收據同源），其次帳單收款，最後才用合約 PayDate（只顯示、不修正）；沒有則「還沒繳費」。下方「應繳・已收・未繳」為該合約帳單欄位加總。
- 堂數制顯示「剩 N 堂」（還沒上＋還沒排日期）；月結課每個月標題下顯示「應繳 NT$ x　已收 m/d NT$ y」。家長回報待確認時寫出回報日期。
- 每堂只寫「第 n 堂」：上課日 API 沒有每堂扣幾堂（G-011），不再逐堂倒數。純顯示，金額與 API 不變。
