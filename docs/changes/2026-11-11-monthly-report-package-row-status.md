## 2026-11-11 — fix(billing): 當月學收的月結方案行，沒有應收時不再顯示「未收」
<!-- release-notes: staff_update=staff-2026-11-11-monthly-report-package-row-status -->
- 當月學收裡，本月沒有上課也沒有帳單的月結方案仍會列出，但狀態顯示「—」，不再算成未收（in-app #537）。方案行同時補上科目（方案名稱）與老師。
- 本月有帳單的月結方案，已收／部分／未收依該月帳單與收款判定；同一個方案裡有人已有帳單、另一科有上課卻還沒開帳單時，顯示「待確認」，不會算成已收。
- 一般課程列、匯出檔與提醒條件都沒有改動。
