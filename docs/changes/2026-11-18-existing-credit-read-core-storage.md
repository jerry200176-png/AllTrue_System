本階段只提供相同單價／堂長的純計算與空稽核儲存，不提供新的預覽路由或操作入口。後續須接上完整來源／目的課程、現行校區、原始收款與釋出堂次檢查，才能提供實際轉用；目前不取消課堂、改帳或替使用者確認。

新增空的整批配置稽核表及既有轉用表的 nullable 關聯，不回填既有資料；正式 migration 依現行原生閘門處理。程式回滾不刪除稽核，尚未完成寫入、還原、授權路由及操作介面，不能據此宣稱回報已交付。
