## 2026-10-28 — fix(billing): 「舊制無帳單／需核對」月結與共用方案也能處理（in-app #428／#438）

- 課程只有舊「已收」標記、沒有收款紀錄時，學生帳務的合約卡可以「已收過，補登收款」或「其實沒收，改成未繳」，但之前只有單一堂數制課程看得到；月結與共用方案只有標籤、沒有任何動作，標籤清不掉。現在任何課程型態都走同一條規則（`PaymentReportController::legacyFlagRefusal`）與同一套稽核。
- 共用方案：收款證據與繳費回報看整個方案；動作出現在方案主卡，其他成員卡指向主卡；「改成未繳」把方案與方案內同學生所有課程的標記一起拿掉（稽核 `row_count` 記改了幾門課），不動任何帳單或收款。月結補登收款依收款日期歸屬的月份開帳單，金額不可超過該期應收。
- 帳務中心「已結清」的「舊制無帳單」改用與課程管理、提醒相同的收款證據規則：付清的共用方案，其他成員不再被誤標；說明文字指向兩個動作。
- 不需 migration、沒有新路由；回滾＝還原這個 PR。
