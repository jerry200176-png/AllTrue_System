# 確認不收的課程不再產生繳費單
<!-- release-notes: staff_update=staff-2026-11-16-waived-course-payment-slip -->

已標記「確認不收」的課程，即使保留舊合約總額且沒有帳單，繳費單入口也會回覆不需產生繳費單。原有分校授權先檢查，再判斷結案狀態；其他分校與不存在的課程仍回相同 403，不透露資料。

這只是 in-app #551（#5362）的終止課程通知守衛：不改單價 0 的規則，不把單價 0 自動視為免費，不更正合約金額、帳單、收款或歷史堂次。同學生其他課程的收據不會當成本課的付款證據。#550 的過去未點名堂次由 #5398 另行處理，既有資料未修復。

回滾為 revert 本 PR 的 squash commit 並依既有流程部署；沒有資料轉換需要撤銷。發布後用既有授權角色唯讀核對同一課程的繳費單回應，不建立或撤銷任何款項。回報者驗收另列。
