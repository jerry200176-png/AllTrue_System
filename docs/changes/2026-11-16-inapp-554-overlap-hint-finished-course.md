## 2026-11-16 — fix(billing): 已經上完的堂數制課程不再提示「本期順延與下一期重疊」（in-app #554）
<!-- release-notes: staff_update=staff-2026-11-16-inapp-554-overlap-hint -->
- 學費收款清單會在「這一期順延後，跟下一期的開課日重疊」時提醒主任調整。判斷用的是合約登記的結束日；課程提前上完後這個日期不會往回改，所以已經剩 0 堂的課也被提示「順延至某天」，打開明細卻看不到那一天。
- 現在堂數制課程剩 0 堂時不再顯示這個提示（沒有課可以跟下一期重疊）。還有堂數的課、月結制的課照舊提醒。沒有改任何資料。
