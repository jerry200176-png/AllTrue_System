## 2026-11-28 — feat(exams): 段考每科可寫「老師的話」
<!-- release-notes: staff_update=staff-2026-11-28-exam-parent-comment -->
- 新增：段考登分表每位學生多一個「老師的話」按鈕，展開後每科一格（最多 500 字），跟分數一起按「儲存」。有寫的列會顯示「已寫 N 科」。要先有分數或勾缺考才能存。
- 規則跟分數一樣：老師只能在開放登分期間寫自己學生的；段考關閉後只有主任能改，且要填原因；每次修改都留紀錄。只改分數不會清掉已寫的話。
- 只改老師的話時，修改紀錄寫「老師的話已更新」，分數格不會出現「改過」。
- 家長畫面在之後的更新上線，這次家長還看不到。
- 資料：`exam_scores` 新增一欄 `parent_comment`（可空、無預設、不回填）。`notes` 維持內部用途，不給家長看。
