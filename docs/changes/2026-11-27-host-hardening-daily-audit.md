## 2026-11-27 — ops(security): 主機安全檢查改成每天自動跑 (#887)
<!-- release-notes: silent_ship=silent-2026-11-27-host-hardening-daily-audit -->
<!-- silent-reason: 只在每日健康檢查多一個唯讀步驟；不影響任何使用者功能。 -->
- 每日的 Pi 健康檢查（`pi-health.yml`）多一步唯讀檢查：防火牆是否啟用、SSH 是否關閉密碼登入與 root 登入（root 必須是明確的 no；讀不到有效設定就算未通過）、fail2ban 是否在跑、對外開的 port 是否只有 22/80/443。
- 公開的執行紀錄只顯示「幾項未通過」。哪幾項、開了哪些 port，只在每週一透過既有的私下維運通知送出（有問題才送）。有問題時該次執行顯示警告，不會讓整個檢查變紅。
- 不改主機任何設定、不需要密碼。要修正檢查出的問題仍需另外核准。
