## 2026-11-06 — fix(billing): don't flag a month as 需核對 before it ends; trim course-manager text (in-app #510)
<!-- release-notes: staff_update=staff-2026-11-06-month-not-ended -->
- Display only. The course list and course manager no longer show 需核對 / 「帳單總額與堂次試算不同」 for a month that has not ended (Asia/Taipei) when the lesson-based total is 0 only because every lesson is still scheduled (`MonthlyPeriodPaymentService::forDisplay`, used by the student-class list). Collection, confirm and every other money path read the unchanged `batch()` / reconciliation result, so they are identical to main. After the period ends, or once lessons are held, the flag shows as before. Course manager 月結 panel: removed the 怎麼處理 heading, bullets and fallback sentence; the lesson-date table lists only months with a real gap and no longer prints 已有帳單服務期間. No migration.
