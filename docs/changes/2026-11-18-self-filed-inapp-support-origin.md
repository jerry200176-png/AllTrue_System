# 自填回報的支援答覆
<!-- release-notes: staff_update=staff-2026-11-18-self-filed-inapp-support-origin -->

沿用既有 POP 身分與校區範圍回答自填回報，以成功執行紀錄辨識支援來源，保留真實作者。本人後續補充即使複製支援文字，也不會被當作機器答覆或驗收。支援留言與執行紀錄一併提交；核讀、去重、職責分離、限額與 kill switches 保留。

Catalog20／in-app policy8 會使舊請求與核准失效，須重新核讀建單。歷史缺少來源證據的自填留言不猜測、不補造；回滾程式不撤回已送出的公開回覆。
