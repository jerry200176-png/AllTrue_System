CVE-2026-114509 / GHSA-f9x3-7vq9-cph6 (CRITICAL, published 2026-10-23 21:50 UTC) affects every `laravel/framework` below 12.68.0, so Laravel 8 has no patch, and the CI `Composer audit` gate turned main and every PR red. Reachability review (SEVERITY_MATRIX SEC-03, TD-075 precedent): the backend ships no `config/auth.php`, so no Laravel auth guard is configured and `Illuminate\Auth\TokenGuard` is never constructed; nothing in `backend/app` or `backend/routes` calls the `Auth` facade, `auth()` or `->guard()`, and no route uses the `auth` middleware. Every API request is authenticated by AllTrue's own middleware (`AttachAuthUser` bearer `AuthToken` lookup, `ApiKeyAuth`, `PopMachineAuth`, `AuthenticateTriageToken`). The advisory is added to `config.audit.ignore` with that note; re-review if a Laravel guard is ever configured, and with the framework EOL migration (#977, TD-075). Local `composer audit --no-dev --locked`: no HIGH/CRITICAL left. Rollback is a normal revert.
