# 通知中心與左側收合 - 手動驗收清單

## 1. 基本功能
- [ ] 主任登入後，左側出現「通知中心」頁籤與未讀數 badge。
- [ ] 點擊「通知中心」可進入通知頁，預設顯示未讀通知。
- [ ] 點擊「同步通知」後，能看到新增/更新/解除的結果提示。

## 2. 通知類型覆蓋
- [ ] 繳費（低堂數 / 未繳）可在通知中心產生 `tuition` 通知。
- [ ] Invoice 到期日逾期（`DueDate < 今天` 且 `Status=unpaid/partial`）可產生 `tuition` 通知。
- [ ] 待審學習評量（pending / changes_requested）可產生 `learning_review` 通知。
- [ ] 未識別刷卡（PendingSwipe）可產生 `pending_swipe` 通知。

## 3. 已讀與篩選
- [ ] 單筆通知可「標記已讀」，列表與未讀數同步更新。
- [ ] 「全部標記已讀」可一次清空當前篩選條件下的未讀通知。
- [ ] 「狀態」篩選（未讀 / 已讀 / 全部）正常。
- [ ] 「類型」篩選（繳費 / 評量 / 刷卡）正常。
- [ ] 勾選「包含已解除」可看到已被解除的通知。

## 4. 跨頁跳轉
- [ ] 繳費通知按「前往處理」可跳至課程管理頁。
- [ ] 待審評量通知按「前往處理」可跳至學習評量頁。
- [ ] 未識別刷卡通知按「前往處理」可跳至出缺勤頁。

## 5. 總覽整合
- [ ] 總覽保留「繳費提醒」統計卡（KPI 不變）。
- [ ] 總覽「通知中心摘要」顯示未讀數與前 3 筆通知。
- [ ] 總覽按「前往通知中心」可正確切換頁籤。

## 6. 左側收合
- [ ] 桌面寬度（>900px）可使用左側收合按鈕展開/收合。
- [ ] 收合狀態重新整理後仍保留（localStorage 生效）。
- [ ] 收合後仍可正常切換各功能頁籤。
- [ ] 平板/手機寬度下不破壞既有側欄與底部導覽行為。

## 7. 分校與權限隔離
- [ ] 切換分校時，通知清單會跟著切換且 badge 重新計算。
- [ ] 主任僅能看到所屬分校通知（不可看他校）。
- [ ] super_admin 可依分校參數查看對應通知。
- [ ] 老師帳號不應顯示主任通知中心頁籤與相關資料。
