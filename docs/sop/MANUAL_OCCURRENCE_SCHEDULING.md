# 逐堂手動排課 SOP（#211）

## 適用範圍

僅限 `director`、`admin`、`super_admin` 操作；v1 僅支援獨立堂數課程，不支援 `PackageID` 共用方案。

## 操作流程

1. 在課程建立或編輯畫面選擇「逐堂手動排課」。轉換既有課程時確認歷史與既有未來堂次仍在。
2. 從課程卡按「新增下一堂」，輸入日期與開始時間。課程時長固定沿用課程設定。
3. 先查看額度與衝堂檢查結果，再建立；每次只建立一堂，可重複操作。
4. 重新整理課程管理與智慧月曆，確認堂次已實體化，並可點名、調課、取消。

## 額度與例外

- 預約不直接扣 `RemainingSessions`；可預約額度為「剩餘堂數 − 尚未取消的未來堂次」。
- 實際上課／核准時沿用既有扣堂流程；取消或作廢未來堂次會釋放額度。
- 遇到學生、老師、教室衝堂、跨分校、過去日期、停用課程或額度不足，先修正資料後重試。
- 請假、取消、調課後不會自動補尾堂；需要時由管理角色手動安排下一堂。

## 驗收與回報

部署後以 #211 對應課程新增下一週一堂，確認重新整理後仍存在且可點名。完成部署後將 in-app 回報標記 `resolved`，待回報者確認後才標記 `closed`。
