# 全站問號逐步導覽測試清單

## 目的
- 驗證每個頁面按下 `?` 後可正常啟動逐步導覽。
- 驗證導覽步驟能正確高亮、切換上下步、完成關閉，且不影響原有頁面功能。

## 共用驗收項目（每頁都要測）
- [ ] 右下角 `?` 按鈕可見且可點擊。
- [ ] 點擊後顯示導覽浮層，標題與說明文字正確。
- [ ] 目前步驟目標區塊會被高亮。
- [ ] `上一步` / `下一步` 正常，最後一步顯示 `完成`。
- [ ] 按 `Esc` 或右上 `✕` 可關閉導覽。
- [ ] 關閉導覽後，高亮與遮罩都會清除。
- [ ] 導覽中切換側欄頁面時，導覽會自動關閉（避免指錯頁）。

## 頁面覆蓋清單（App active key）
- [ ] `director`（總覽儀表板）
- [ ] `notifications`（通知中心）
- [ ] `calendar`（智慧排課）
- [ ] `students`（學生管理）
- [ ] `teachers`（老師管理）
- [ ] `course-mgmt`（課程管理）
- [ ] `classroom`（教室管理）
- [ ] `subject-units`（科目數統計）
- [ ] `attendance`（出缺勤管理）
- [ ] `learning`（學習評量表）
- [ ] `profile`（個人管理）
- [ ] `parent`（家長入口）
- [ ] `director-accounts`（主任審核，super admin）

## 角色差異驗證
- [ ] 主任：`calendar` 導覽包含快速排課步驟。
- [ ] 老師：`calendar` 導覽不顯示主任限定步驟，`learning` 導覽含課表區塊。
- [ ] super admin：可在 `director-accounts` 看到導覽步驟。

## 家長入口模式驗證
- [ ] 已登入主系統切到 `parent` 頁，`?` 可啟動導覽。
- [ ] standalone parent 模式（`#/parent` 或 `?parent=1`）也有 `?`，且可啟動導覽。
- [ ] 家長未登入時導覽指向登入卡；登入後導覽可指向學習/課程卡片。

## 回歸風險點
- [ ] 手機版（<= 640px）浮層與按鈕位置不遮擋主要操作。
- [ ] 切換分校後導覽仍可啟動且步驟不錯位。
- [ ] 通知中心、排課頁等大量動態內容頁不會因導覽卡死。
