## 2. Dry-run 規則（策略 A）

### 2.1 自動選擇「保留 SC」啟發式（**非最終決策**）

```
score = SessionCount × 1000 + (Stop=0 ? 100 : 0) − StudentClassID
→ 取最高分者為 keep_sc；其餘 SC 上同日同時段 attended session → cancelled
```

### 2.2 標準 after 狀態

| 欄位 | 變更 |
|------|------|
| `ClassSession.Status` | `attended` → **`cancelled`** |
| `ClassSession.Note` | 追加 `資料修復 dry-run #189-191 — 跨約重複，保留 SC{keep}` |
| `StudentClass.Stop` | 幽靈殼（SessionCount=0 單日殼）→ **Stop=1**（#189 SC2264） |
