# AllTrue 主任實作挑戰卡 (Director Hands-on Challenge Sheet)

> **主任姓名**：__________________  
> **所屬分校**：__________________  
> **分校學生規模**：約 ______ 人  
> **培訓目標**：35 分鐘內獨立完成主任每日營運閉環（晨間工作台巡檢 → 學生課程購課詳情 → 課表追蹤 → 評量審核）

---

## 🌟 核心理念：以工作台為中樞，不迷路、不漏單
- **晨間 5 分鐘**：開「主任儀表板」，快速清點今日風險、待辦、異常出席。
- **日間營運**：學生諮詢加購課、查詢排課，在「學生名冊」一鍵查閱。
- **傍晚收尾**：在「學習評量」審核老師繳交的教學紀錄，確保分校教學品質。

---

## 🎯 挑戰任務一：主任儀表板 3 分鐘晨間巡檢 (時限：5 分鐘)

*情境：一早抵達分校，需要立刻掌握今日營運大局。*

- [ ] **步驟 1.1**：登入系統，進入「主任儀表板」（首頁）。
- [ ] **步驟 1.2**：若負責多個分校，在左側或頂部切換至今天駐點的分校，注意系統彈出的分校切換提示訊息。
- [ ] **步驟 1.3**：檢視首頁頂部 4 大核心營運數據（在讀學生、今日排課堂數、待審評量、待繳學費）。
- [ ] **步驟 1.4**：檢視「今天要處理的事」聚焦面板，找出目前優先度最高的一項待辦（例如：逾期收款、異常點名或待審評量）。
- [ ] **自我驗證**：我能說出今日最需優先跟進的事項，並透過卡片上的按鈕直達該功能。

---

## 🎯 挑戰任務二：學生名冊查核與課程詳情展開 (時限：10 分鐘)

*情境：家長來電詢問孩子（例如：林小明）剩餘多少堂數、想加購課程，主任需在電話中即刻回覆。*

- [ ] **步驟 2.1**：點擊左側「學生名冊」，進入學生清單。
- [ ] **步驟 2.2**：利用搜尋欄輸入指定學生姓名或電話。
- [ ] **🌟 亮點體驗**：找到該學生列後，操作欄提供清晰的 **「課程/購課」** 按鈕（亦可點擊列首展開圖示）。
- [ ] **步驟 2.3**：點擊 **「課程/購課」**，展開下方「學生課程安排」面板。
- [ ] **步驟 2.4**：查閱該學生目前各科目的「剩餘堂數 / 總堂數」與付款方式（月結或堂數制）。
- [ ] **步驟 2.5**：點擊展開區塊內的「新增課程」按鈕，體驗排課與購課填寫表單（演練時可點擊取消退出，不實際寫入正式資料）。
- [ ] **自我驗證**：我能透過操作欄的「課程/購課」按鈕，在 3 秒內展開並查到學生的可用堂數！

---

## 🎯 挑戰任務三：智慧課表查詢與排課調度 (時限：8 分鐘)

*情境：確認某位老師今天下午或明天是否有空堂能安排補課。*

- [ ] **步驟 3.1**：點擊左側「智慧課表」。
- [ ] **步驟 3.2**：使用頂部「教師」下拉選單篩選特定授課教師。
- [ ] **步驟 3.3**：檢視該教師的週課表，識別綠色（已排課）與空白時段（可用空堂）。
- [ ] **自我驗證**：能在課表中快速切換日/週視圖，並找出教師可補課時段。

---

## 🎯 挑戰任務四：學習評量審核與品質把關 (時限：10 分鐘)

*情境：老師完成今日課堂並送出學習評量，主任需審核評語品質，通過後才能推播至家長端。*

- [ ] **步驟 4.1**：點擊左側「學習評量」。
- [ ] **步驟 4.2**：切換至「待審核」狀態標籤。
- [ ] **步驟 4.3**：點選一筆由老師提交的評量紀錄，展開檢視課堂教材進度與教師評語。
- [ ] **步驟 4.4**：確認評語得體完整後，點擊「核准」（若評語過於簡略，可點擊「退回修改」並附註改善建議）。
- [ ] **自我驗證**：評量紀錄狀態變更為「已核准」，已順利納入分校教學履歷。

---

## 🎯 挑戰任務五：敏感財務模組與安全防護認識 (時限：5 分鐘)

*情境：主任需要收取現金學費或查閱分校學費月報表。*

- [ ] **步驟 5.1**：點擊左側「學費收款」或「學費報表」。
- [ ] **步驟 5.2**：觀察系統彈出專屬「主任安全 PIN 碼」鎖定視窗。
- [ ] **步驟 5.3**：輸入分校專屬安全 PIN 碼解鎖，體會閒置自動上鎖安全機制。
- [ ] **自我驗證**：理解 PIN 碼是在公用櫃檯電腦上保護分校收支機密的第一道防線。
