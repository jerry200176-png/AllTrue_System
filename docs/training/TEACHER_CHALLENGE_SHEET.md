# AllTrue 教師實作挑戰卡 (Teacher Hands-on Challenge Sheet)

> **學員姓名**：__________________  
> **所屬分校**：__________________  
> **授課科目**：__________________  
> **培訓目標**：30 分鐘內獨立完成每日教學黃金閉環（課表檢視 → 出席點名 → 課堂評量填寫）

---

## 🌟 核心理念：每日 3 次，每次 2 分鐘
- **上班到班**：開工作台看今天有哪幾堂課、學生請假狀況。
- **下課即刻**：勾選點名確認到班（扣堂即時連動、家長安心）。
- **當日下班**：隨手填寫課堂評量，送交主任審核。

---

## 🎯 挑戰任務一：確認今日工作台與課堂 (時限：5 分鐘)

*情境：你剛走進分校教室，準備展開今天的教學。*

- [ ] **步驟 1.1**：登入系統，進入「教師工作台」（首頁）。
- [ ] **步驟 1.2**：若你任教於多個分校，檢查畫面左上角或頂部的「切換分校」按鈕，確認目前所在分校是否正確。切換時請注意畫面上出現的切換提示。
- [ ] **步驟 1.3**：在「今日排課」區塊中，找到今天第一堂要授課的學生姓名、時間與科目。
- [ ] **自我驗證**：我能清楚看見今天的學生名單，且知道下一堂課在幾點開始。

---

## 🎯 挑戰任務二：課堂結束，完成批次點名 (時限：8 分鐘)

*情境：第一堂課順利下課，所有學生均準時出席。你需要在 1 分鐘內完成扣堂點名。*

- [ ] **步驟 2.1**：在首頁點擊「開始點名」，或從左側選單進入「出缺勤管理」。
- [ ] **步驟 2.2**：在「今日待點名堂次」清單中，勾選「全選」核取方塊（或逐位勾選出席學生）。
- [ ] **步驟 2.3**：點擊橘色按鈕 **「全部到班（N）」**。
- [ ] **步驟 2.4**：系統跳出批次成功提示，且待點名清單更新。
- [ ] **🌟 亮點體驗**：今日堂次點名全部完成後，畫面中央出現綠色打勾卡片：  
  **「今日待點名堂次已全部完成！下一步：填寫課堂評量」**。
- [ ] **自我驗證**：點名已送出，我看到綠色完成卡片與「前往填寫評量」按鈕！

---

## 🎯 挑戰任務三：即時填寫課堂學習評量 (時限：10 分鐘)

*情境：趁著記憶猶新，記錄學生剛才課堂的進度與表現，供主任審核後傳送給家長。*

- [ ] **步驟 3.1**：直接點擊點名完成卡片上的 **「下一步：填寫課堂評量」**（系統將自動帶入分校並開啟評量頁面）。
- [ ] **步驟 3.2**：在學習評量頁面，點擊右上角「新增評量」按鈕。
- [ ] **步驟 3.3**：選取剛才點名的學生、課程堂次，並填寫：
  - 課堂進度／教材單元
  - 專注度與隨堂表現星等
  - 給家長的客製建議或課堂亮點（1-2 句話）
- [ ] **步驟 3.4**：點擊「儲存紀錄」。
- [ ] **自我驗證**：評量列表中已出現該筆紀錄，狀態顯示為「待審核」，已通知主任。

---

## 🎯 挑戰任務四：用我的課表掌握本週排班 (時限：5 分鐘)

*情境：下課前學生詢問下週是否同一時間上課。*

- [ ] **步驟 4.1**：點擊左側選單進入「智慧課表」。
- [ ] **步驟 4.2**：在週曆視圖中，切換至「下週」，確認該學生的下一次上課時間。
- [ ] **自我驗證**：成功在課表中確認學生未來的預排時段。
