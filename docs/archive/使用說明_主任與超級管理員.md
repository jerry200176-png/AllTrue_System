# 主任 / 超級管理員使用說明

> **導讀**：本檔聚焦 **Developer Bypass 假登入** 與超級管理員常見誤會；**完整角色 SOP** 以 [`ROLE_PLAYBOOK.md`](ROLE_PLAYBOOK.md) 為準。  
> 若與後續產品改版衝突，以程式碼與 [`CHANGELOG.md`](CHANGELOG.md) 為準。

## 為什麼看不到老師、系統好像沒變？

**很可能原因：您用了畫面上的「Developer Bypass」按鈕（Director / Teacher）登入。**

- 那是**假登入**，不會打後端、沒有真正的 token。
- 所有需要權限的 API（老師列表、學生列表等）都會 401，所以**老師列表會是空的**。

**請改用「真實登入」：**

1. 在登入頁輸入**資料庫裡存在的帳號**（Email）與密碼。
2. 點「登入 (Login)」，不要點 Developer Bypass 的 Director。
3. 登入成功後，老師列表、學生列表等才會正常顯示。

---

## 沒有「主任專屬帳號」或「超級管理員專屬入口」？

目前前端**沒有**另外做：

- 主任專屬註冊頁
- 超級管理員專屬登入入口
- 超級管理員專用設定頁

**現有設計是：**

- **同一個登入頁**，所有人（主任、老師、超級管理員）都用 Email + 密碼登入。
- **角色由資料庫決定**：`User.type` = `'S'` → 超級管理員，`'T'` → 老師，`'U'` → 待審核，其他 → 主任。
- 您已經用 SQL 把某個帳號設成 `type = 'S'`，所以**用那個帳號做「真實登入」**就會是超級管理員。

---

## 超級管理員怎麼用？

- **用法和主任一樣**：同一個系統、同一個選單。
- **差別**：超級管理員會看到**所有分校**的資料（老師、學生、排課等），不會被單一分校篩掉。
- 登入後左側會顯示「**超級管理員 Super Admin**」，分校切換器會列出所有分校（若後端有回傳）。

沒有另外的「超級管理員專用功能」或專屬頁面，只是權限比較大（看全部）。

---

## 如何新增主任帳號？

目前沒有「主任註冊」畫面，做法是**在資料庫新增一筆 User**：

1. 在 `User` 表新增一筆：`LoginName` = 主任的 Email，`PSW` = bcrypt 密碼，`Name` = 顯示名稱，`type` = 空或非 `T`/`U`（即主任），`phone` = 0。
2. 在 `UserCampus` 表新增該主任可管理的分校（`UserID`, `CampusID`）。

或可請後端加一個「建立主任帳號」的 API，再由前端做一個簡單表單（之後可再補）。

---

## 總結

| 問題 | 說明 |
|------|------|
| 看不到老師 | 請用「真實登入」（Email+密碼），不要用 Developer Bypass。 |
| 超級管理員怎麼用 | 用已設成 Super Admin 的帳號登入，用法同主任，但可看所有分校。 |
| 沒有主任專屬帳號 | 前端沒有主任專屬註冊；主任帳號需在資料庫建立，或之後加 API/表單。 |
