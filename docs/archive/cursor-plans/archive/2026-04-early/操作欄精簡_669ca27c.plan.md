# 操作欄精簡計畫

## 分析：哪些功能屬於哪一層

| 功能 | 層級 | 現在入口 | 判斷 |
|------|------|---------|------|

**單堂層級（日期粒度）** -- 已由「上課日期點擊 → 單堂操作面板」完整涵蓋：
- 標記已上/未上/請假/缺席/遲到
- 補請假（沖回堂數）
- 調課（選新時段）
- 取消堂次

**課程層級（整門課粒度）** -- 必須留在操作欄：
- 編輯課程（改老師/費率/類型/教室等）
- 加購堂數（買更多堂數）
- 刪除課程

**可歸入單堂操作的** -- 從操作欄移除：
- 加課/補登 → 改放進單堂操作面板底部，語意更清楚（「在這門課新增一堂」）

## 改動方案

右側操作欄從目前的 `單堂操作` + `課程設定（4項下拉）` 精簡為：

```
[ 編輯 ]  [ 加購 ]  [ 刪除 ]
```

三個小按鈕一排，不再需要下拉選單。

同時在單堂操作面板的底部加一個「新增堂次」入口（原本的加課/補登），讓它歸屬於日期層級。
