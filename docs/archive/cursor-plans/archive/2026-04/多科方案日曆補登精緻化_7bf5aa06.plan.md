# 多科方案日曆補登精緻化

## 版面設計

```
┌─────────────────────────┬─────────────────────────┐
│  方案基本資料（2欄網格） │  月曆（補登用）          │
│  ─────────────────────  │  [ 上月 ] 2026-04 [ 下月]│
│  科目清單               │  一 二 三 四 五 六 日    │
│  ┌──────────────────┐   │  [灰] [●] [●] ...        │
│  │科目 老師 時長 開始│   │  ─────────────────────  │
│  │日期    [✕]       │   │  點選科目                │
│  │● 數學 3堂已補登  │   │  ◉ 數學  ○ 英文  ○ 數學 │
│  └──────────────────┘   │  ─────────────────────  │
│  ＋ 新增科目            │  方案摘要                │
│                         │  總 24 ｜補登 3 ｜餘 21  │
└─────────────────────────┴─────────────────────────┘
```

## 日曆行為（package mode）

- 只有今天以前的日期可點選（未來日期 `muted` 且 disabled）
- 點選某日 → 加入「目前選擇科目」的 `confirmed_dates`（toggle：再點一次移除）
- 每個科目顯示不同顏色標記（最多 10 科，用色相旋轉）
- 若同一天已在某科 confirmed，顯示小彩色方塊提示

## 科目列精緻化

每行科目改為卡片樣式：
```
┌ 科目: 數學   老師: 王老師   時長: 2h   開始: 2026-04-01   [✕] ┐
│ ● 3 堂已補登  2026-04-07  2026-04-10  2026-04-14            │
└─────────────────────────────────────────────────────────────┘
```
- chips 顯示已補登日期（可點叉移除），不再需要展開/收合按鈕
- 整體邊框、圓角、輕陰影

## 修改範圍

**只修改 [`frontend/src/components/UniversalClassScheduler.vue`](frontend/src/components/UniversalClassScheduler.vue)**

1. package mode 右側新增月曆（複用現有 `calendarCells` 計算邏輯，另建 `pkgCurrentMonth` ref）
2. 新增 `pkgActiveSubjectIdx` ref（目前選擇要補登哪個科目）
3. 新增 `onPkgDateClick(cell)` - 只允許 today 以前，toggle 到 `pkgForm.subjects[pkgActiveSubjectIdx].confirmed_dates`
4. 科目列改為卡片樣式，chips 直接顯示於卡片下方
5. 移除舊的 `_showDates` / `_dateInput` 邏輯（但保留 start_date + confirmed_dates payload，後端不動）
6. 月曆標記：每個日期若在某科 confirmed_dates 中，顯示彩色圓點
