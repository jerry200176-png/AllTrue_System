# 當月學收月報實作

## 現況

- 側欄「財務收款」已有：催繳名單、帳單列表、科目數統計
- 帳單列表（[`BillingList.vue`](frontend/src/pages/BillingList.vue)）綁 `Invoice` 表，多數分校未開帳單故列表空
- CTO 規格已撰寫完成：[`docs/CTO_SPEC_BRANCH_MONTHLY_TUITION_REPORT.md`](docs/CTO_SPEC_BRANCH_MONTHLY_TUITION_REPORT.md)
- 後端無現成的「學生 x 科目 x 月」堂數與學收 API

## 設計決策（採規格預設方案）

- **月有效堂數口徑**：`ClassSession` 在指定月且 `Status in ('attended','completed','late')` 的筆數（規格 Option A）
- **費率**：`StudentClass.Rate`；若 null/0 則 fallback `Charge / SessionCount`
- **月結制**：同按堂數 x Rate 統一計算（規格 Option X）
- **列維度**：每列 = 一筆 `StudentClass`（學生 x 科目 x 老師）
- **頁面名稱**：「當月學收」，`active = 'tuition-report'`

## 1. 後端：新增 API

**檔案**：[`backend/app/Http/Controllers/FinanceController.php`](backend/app/Http/Controllers/FinanceController.php)

新增方法 `branchMonthlyTuition`：

```php
// GET /api/v1/finance/branch-monthly-tuition?branch_id=&year=&month=
public function branchMonthlyTuition(Request $request)
```

- 用現有 `getCampusIds()` 做分校隔離
- 查 `StudentClass` where `Stop = 0`，join `Student`（取名字、`CampusID` 過濾）
- 子查詢 `ClassSession`：`SessionDate` 在 year-month 範圍 且 `Status in ('attended','completed','late')`，GROUP BY `StudentClassID` 得 `monthly_sessions`
- 計算 `rate = Rate ?: (Charge / SessionCount)`，`monthly_tuition = monthly_sessions * rate`
- 回傳分頁結果 + `summary`（全量 total_students / total_sessions / total_tuition）

**路由**：[`backend/routes/api.php`](backend/routes/api.php) director 區塊加一行：

```php
Route::get('finance/branch-monthly-tuition', [FinanceController::class, 'branchMonthlyTuition']);
```

**回傳結構**（與規格一致）：

```json
{
  "data": [
    {
      "student_class_id": 123,
      "student_name": "王小明",
      "subject": "數學",
      "teacher_name": "李老師",
      "class_type": "one_on_one",
      "rate": 600,
      "monthly_sessions": 8,
      "monthly_tuition": 4800
    }
  ],
  "summary": {
    "total_students": 30,
    "total_sessions": 245,
    "total_tuition": 147000
  },
  "meta": { "current_page": 1, "last_page": 2, "per_page": 50, "total": 78 }
}
```
