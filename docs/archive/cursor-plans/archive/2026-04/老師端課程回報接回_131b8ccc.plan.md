# 老師端課程回報入口接回

## 問題根因

`ReportDiscrepancyModal.vue` 元件完整存在，後端 API、`scheduleDiscrepanciesApi.js` 也都齊全，但它從未被任何老師端頁面 import 或使用。

- [`frontend/src/components/ReportDiscrepancyModal.vue`](frontend/src/components/ReportDiscrepancyModal.vue) — 完整 modal，支援 form 與 readonly 兩種模式
- [`frontend/src/lib/scheduleDiscrepanciesApi.js`](frontend/src/lib/scheduleDiscrepanciesApi.js) — `createDiscrepancy`、`fetchActiveForSession`、`withdrawDiscrepancy` 均已可用
- [`frontend/src/pages/TeacherHomePage.vue`](frontend/src/pages/TeacherHomePage.vue) — 週課表的每個 `.th-event` 課程格，目前只有「填寫評量」一顆按鈕，無任何回報邏輯

## 修改範圍

只動 `TeacherHomePage.vue`，不動 modal 元件本身。

## 修改細節

### 1. 新增 import

在 `<script setup>` 的 import 區塊加入：

```js
import ReportDiscrepancyModal from '../components/ReportDiscrepancyModal.vue';
import {
  createDiscrepancy,
  fetchActiveForSession,
  withdrawDiscrepancy,
} from '../lib/scheduleDiscrepanciesApi.js';
```

### 2. 新增 reactive 狀態

```js
const reportModalOpen = ref(false);
const reportModalReadonly = ref(false);
const reportModalSession = ref(null);   // { sessionId, date, time, subject, student, branchId }
const reportModalExisting = ref(null);  // 已有回報時傳入 existing prop
```

### 3. 在每個 `.th-event` 課程格加「回報」按鈕

在現有 `<button v-if="ev.formStatus === 'missing'...">` 旁邊（約第 161 行），補一顆旗幟按鈕：

```html
<button
  class="th-report-btn"
  :title="ev.activeReport ? '查看回報' : '回報課表有誤'"
  @click="openReport(ev)"
>
  <span class="material-symbols-outlined"
    :style="ev.activeReport ? 'color:#ef4444' : ''">flag</span>
</button>
```

`ev.activeReport` 的值從 `activeReportMap`（下方 computed）取得。

### 4. 載入課表時批次查詢已有回報

在 `loadWeekSchedule()` 完成後，對所有有 `sessionId` 的課程批次呼叫 `fetchActiveForSession`，結果存進：

```js
const activeReportMap = ref({});  // { [sessionId]: discrepancy | null }
```

若課程數不多（< 30），可 `Promise.allSettled` 並行查；若要保守一點，只在使用者點按鈕時懶載入。

### 5. `openReport(ev)` 函式

```js
async function openReport(ev) {
  reportModalSession.value = {
    sessionId: ev.sessionId,
    date: ev.date,
    time: `${ev.startTime}~${ev.endTime}`,
    subject: ev.subject,
    student: ev.studentName,
    branchId: ev.branchId,
  };
  // 若已有回報，以 readonly 模式開啟
  const existing = activeReportMap.value[ev.sessionId] ?? null;
  reportModalExisting.value = existing;
  reportModalReadonly.value = !!existing;
  reportModalOpen.value = true;
}
```

### 6. 處理 submit / withdraw

```js
async function handleReportSubmit(payload) {
  const sess = reportModalSession.value;
  await createDiscrepancy({
    branch_id: sess.branchId,
    class_session_id: sess.sessionId,
    session_date: sess.date,
    time_range: sess.time,
    subject: sess.subject,
    student_name: sess.student,
    ...payload,
  });
  reportModalOpen.value = false;
  // 刷新該 session 的 active report 快取
  await refreshActiveReport(sess.sessionId);
}

async function handleReportWithdraw(id) {
  await withdrawDiscrepancy(id);
  reportModalOpen.value = false;
  await refreshActiveReport(reportModalSession.value?.sessionId);
}
```

### 7. 在 template 掛載 modal

在 `</template>` 結束前加：

```html
<ReportDiscrepancyModal
  v-if="reportModalOpen"
  :open="reportModalOpen"
  :session-context="reportModalSession"
  :readonly="reportModalReadonly"
  :existing="reportModalExisting"
  :branch-id="reportModalSession?.branchId"
  @close="reportModalOpen = false"
  @submit="handleReportSubmit"
  @withdraw="handleReportWithdraw"
/>
```

### 8. 補一點 CSS

為 `.th-report-btn` 加樣式（與 `.th-fill-btn` 並列），旗幟在已有回報時以紅色顯示。
