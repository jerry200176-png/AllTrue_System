# PLAN：正職薪資要件照總部 115.07 公告重做（P0）

**Risk-Class:** R3（薪資金額）
**權威規則：** 台北全真總管理處公告（115.05.11 公告，115.07.01 生效）＋附檔 1 科目數獎金表。先前依「蘆洲長樂 docx」做的分校版規則作廢。
**一段課：** 2 小時。

## Founder 決定（2026-11-14）

1. 科目數獎金、一對三獎金、20 科 +5% 三個公式照總部結算表。
2. 每週 16 段看排課：老師自己請假不算，學生請假照算。
3. 正課、輔導、試聽都用「時數 ÷ 2」算段數。
4. 假日 16 小時（0–10%）與平日下午 5 段課（0–5%）倍率：系統先算建議值，主任可在範圍內改並寫原因，總部核准後生效。
5. 科目數用 AllTrue 自己的算法，數字來源就是「科目數統計」頁（`SubjectUnitsTimelineService`），不另算一套。

## 公式

```
核薪總科目數 = (正課 + 輔導試聽) ÷ 8         ← 科目數統計頁的數字；一對三的課算在正課裡
科目數獎金   = 附表[無條件捨去(核薪總科目數)]
一對三獎金   = 一對三總計 × 100
教師倍率     = 100 + 假日(0–10) + 平日下午(0–5) + (正課 ÷ 8 ≥ 20 ? 5 : 0)
               + 行政加給(0–10) + 特殊表現(每項 5) + 扣除(每項 −10)
倍率後獎金   = 無條件捨去((科目數獎金 + 一對三獎金) × 倍率)
保底         = 到職前 3 個月且每週都滿 16 段 → max(2000, 倍率後獎金)
總發放       = 本薪 + 16 段課獎金 + 倍率後獎金(或保底) + 現金加扣款
```

數字只放 `backend/config/teacher_salary.php`；規則只寫在 `TeacherEligibilityPolicy`。
