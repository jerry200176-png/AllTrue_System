# 老師評量完成率與軍階激勵 v1

## 產品決策

主任需要知道哪裡要協助，但「填寫率低」不能直接等同於老師混或教學品質差。因此 v1 顯示近 7／14／30 天的已填／應填、樣本數與待跟進狀態，預設只在主任的完整營運分析區載入。

## 統計與防刷分規則

- 沿用既有 API：已到班、遲到、已完成堂次列入分母；取消與請假排除。
- 代課堂次歸給實際代課老師；評量取最新且未作廢紀錄，Progress 有內容才算已填。
- 少於五堂只顯示「資料累積中」，不列為低效，也不以單一百分比做排名。
- 主任畫面依「需要跟進 → 提醒關注 → 資料累積中 → 穩定完成」排序，提供評量審核入口。
- v1 不因儲存空白評量自動發 XP；軍階仍獎勵完整教學流程與持續使用，避免為刷分亂填。

## 權限與邊界

本切片只呼叫既有主任分校範圍 API，不新增資料寫入、XP、資料表或公開同儕排名。老師端仍只看自己的進度與既有軍階顯示；後續若要做任務、徽章或個人化提醒，需另立產品決策並補上內容品質與稽核規則。

## 驗收

主任打開「完整營運 → 近期紀錄與分析」後，可看到評量完成率；可切換期間、遇到 API 失敗可重試；樣本不足不會被標成需要跟進；列表不顯示競爭名次或 XP。
