# PLAN：正職薪資要件改為 115.07 結算表

**Risk-Class:** R2（薪資計算與主任可見金額）  
**Worktree:** `fulltime-settlement-ui-20260816`  
**權威規則：** `115.07起 薪資規定_蘆洲長樂.docx`；畫面欄位對齊主任提供的正職結算截圖。  
**非範圍：** 分校／老師業績分頁、兼職結算、營運科目數獎金、Excel 匯出、全勤／勞健保（docx 未列）、行政加給（TD-077）。

## 公式

```
核薪總科目數 = 正課科目數 + 輔導／試聽科目數
倍率後獎金 = (科目數獎金 + 一對三獎金) × 教師倍率
總發放金額 = 本薪 + 每週16段課獎金 + 倍率後獎金
教師倍率 = 100% + 假日16小時(0或10) + 平日下午段數% + 特殊表現% + 科目數≥20的+5% + 已核准扣除%
```

docx 薪資結構：本薪 ＋ 每週16段課獎金 ＋ 科目數獎金 ＋ 一對三獎金；倍率只乘在科目數／一對三獎金上（既有 `FulltimeSettlementComposer`）。

## 本 PR 行為變更

1. **假日 16 小時：** 每個假日 `常態排課時數 + 假日假時數 >= 16` 才給 10%，否則 0%。假日假可補足缺口（覆蓋先前「假日假不創造時數」）。
2. **科目數：** 正課與輔導／試聽與一對三分桶；科目數獎金查核薪總科目數、一對三獎金查一對三總計；非整數在附件 1–50 表相鄰列線性內插。
3. **UI：** 「正職薪資要件」改為結算欄（底薪、科目數拆分、獎金、倍率拆解、倍率後獎金算式、加扣款列 16 段課、總發放）。補登審核區保留。可選結算月份並重新計算。
