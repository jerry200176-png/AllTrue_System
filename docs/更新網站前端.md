# 更新網站前端（讓修改出現在畫面上）

您用 **http://localhost:8080** 開網站時，看到的是 **已打包好的舊版**（在 `backend/public/`），不是即時讀 `frontend/src/` 的程式碼。  
所以改完 `frontend/src/` 後，要「重新打包 + 複製到後端」才會在 8080 看到新畫面。

## 方法一：手動執行（PowerShell，在專案根目錄）

```powershell
# 1. 打包前端（會產生 frontend/dist/）
cd frontend
npm run build
cd ..

# 2. 把打包結果複製到後端（覆蓋 backend/public 的 index 和 assets）
Copy-Item -Path frontend\dist\index.html -Destination backend\public\index.html -Force
Remove-Item -Path backend\public\assets\* -Force -ErrorAction SilentlyContinue
Copy-Item -Path frontend\dist\assets\* -Destination backend\public\assets\ -Force
```

完成後重新整理瀏覽器（建議 **Ctrl+F5** 強制重新載入），就會看到最新修改。

---

## 方法二：用開發模式（即時看到修改）

若想改程式後**馬上**看到結果、不用每次手動打包：

1. 確認 Docker 已啟動（後端與 API 正常）：  
   `docker compose up -d`
2. 在專案根目錄開一個終端機，執行：  
   `cd frontend` → `npm run dev`
3. 用瀏覽器開 **http://localhost:5173**（不要開 8080）。

此時 5173 會讀取 `frontend/src/`，改完存檔就會自動更新畫面；API 會透過 Vite 代理打到 8080。

---

## 總結

| 開的網址 | 看到的版本 | 要看到新修改該怎麼做 |
|----------|------------|------------------------|
| http://localhost:8080 | 舊打包檔（backend/public） | 照 **方法一** 打包並複製到 backend/public，再重新整理 |
| http://localhost:5173 | 即時 src（frontend） | 用 **方法二** 跑 `npm run dev`，改完存檔即更新 |

若你一直都是開 8080，又沒做過方法一，就會覺得「修改都沒出現」—— 因為 8080 還在讀舊的打包檔。
