## Dashboard baseline evidence

The authenticated production dashboard was checked at 390 and 1440 CSS pixels on 2026-08-01. The current baseline measured approximately:

| Viewport | Dashboard body | Trust panel | Work area | Finding |
|---|---:|---:|---:|---|
| 390 × 844 | 10,061px tall | 1,473px | 7,100px | Primary actions are far below the fold; CTA discovery is poor |
| 1440 × 900 | 3,070px tall | 927px | 1,294px | Large decision block dominates; detail cards compete with daily work |

These values are evidence for the workbench redesign. The new page must record the same measurements after implementation and show a meaningful reduction in first-action distance without removing required workflows.
