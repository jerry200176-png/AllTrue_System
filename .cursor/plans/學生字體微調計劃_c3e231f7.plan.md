# 學生顯示字體放大實作計劃

## 目標
在不改動資料與流程邏輯前提下，將學生管理頁關鍵資訊字體「放大一點點」，提高可讀性：
- 學生姓名與主要欄位更容易閱讀
- 課程標籤與展開區表格資訊不再過小
- 桌機與手機版維持穩定排版

## 變更範圍（僅前端 UI）
- 主要檔案：[`/home/admin/frontend/src/pages/StudentsList.vue`](/home/admin/frontend/src/pages/StudentsList.vue)
- 只調整該檔 `style scoped` 的字級與行高，不改 API / 資料結構 / business logic
- 不先動全域樣式 [`/home/admin/frontend/src/styles.css`](/home/admin/frontend/src/styles.css)，避免連帶影響其他頁面

## 具體調整策略
1. **先提高主要閱讀區的基準字級（小幅）**
- 學生主表格內容字級：由目前全域 `td` 13.5px 的視覺體感，局部拉高約 +0.5~1px（以 page-level selector 覆蓋）。
- 學生姓名（`student-name-cell` 內 `strong`）再上調一階，讓姓名成為視覺焦點。

2. **同步放大目前過小的輔助資訊**
- `subject-pill`（現 11px）微調至 12px。
- `student-status-badge`（現 10px）微調至 11px。
- `rfid-tag` / `rfid-unbound`（現 0.8em）調整為更穩定可控的 px/rem 字級。
- 展開課程區：`course-inner-table`（現 13px）、`th`（現 11px）、`schedule-slot-line`（現 12px）各上調一階，維持層次差。

3. **維持資訊層級，不做「全部等大」**
- 主要資訊（姓名/剩餘堂數）> 次要資訊（備註/狀態）> 輔助標籤（badge）
- 行高一併微調（約 1.35~1.5）避免放大後顯得擁擠

4. **RWD 安全調整**
- 檢查 `@media (max-width: 768px)` 下表格與按鈕是否擠壓。
- 若手機版橫向擁擠，優先調整 `padding` 與 `gap`，避免把字再縮回去。

## 驗收與回歸檢查
- 在學生列表頁確認：
  - 學生姓名、科目/堂數、RFID、狀態可讀性明顯提升
  - 展開課程表頭與內容字級一致且不擁擠
  - 無欄位截斷惡化、無按鈕重疊
- 手機寬度（<=768）檢查：
  - 表格仍可橫向捲動
  - 操作按鈕可點擊、文字不重疊

## 部署與交付
- 完成前端樣式調整後執行：`cd /home/admin/frontend && npm run deploy`
- 回報內容包含：
  - 實際調整的 class 清單
  - 放大幅度（舊值 -> 新值）
  - 手機/桌機檢查結果
