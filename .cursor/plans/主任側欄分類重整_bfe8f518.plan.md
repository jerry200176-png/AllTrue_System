# 主任側欄導航分類重整

## 現狀問題

「教務核心」群組塞了 8 個項目，混雜了排課、學生、財務、人員、場地管理，不直覺。

## 新分類方案

### 主任側欄 5 群組

```
總覽與通訊        排課與教學         人員管理
─────────       ─────────        ─────────
總覽儀表板        班級行事曆/課表     學生管理
通知中心          課程管理           老師管理
內部聊天          出缺勤管理
                 學習評量表

財務收費          系統設定
─────────       ─────────
催繳名單          教室管理
帳單列表          科目管理
科目數統計        家長 LINE 通知
                 (主任審核)
                 Bug 回報
```

### 對比表

| 現在群組 | 頁面 | 新群組 |
|---------|------|--------|
| 營運總覽 | 總覽儀表板、通知中心、內部聊天 | **總覽與通訊**（不變） |
| 教務核心 | 行事曆、課程管理 | **排課與教學** |
| 教務核心 | 學生管理 | **人員管理** |
| 教務核心 | 催繳名單、帳單列表 | **財務收費** |
| 教務核心 | 老師管理 | **人員管理** |
| 教務核心 | 教室管理、科目管理 | **系統設定** |
| 考勤與評量 | 出缺勤管理、學習評量表 | **排課與教學** |
| 考勤與評量 | 科目數統計 | **財務收費** |
| 系統管理 | LINE 通知、主任審核、Bug | **系統設定** |

### 手機底欄

維持不動（儀表板、行事曆、學生、出勤、更多），「更多」抽屜自動跟隨新群組。

## 修改範圍

唯一需要改的檔案：[frontend/src/App.vue](frontend/src/App.vue)

改 `sidebarNavGroups` computed（約第 760-818 行），將 `isDirector` 分支的 return 陣列從 4 組改為 5 組：
