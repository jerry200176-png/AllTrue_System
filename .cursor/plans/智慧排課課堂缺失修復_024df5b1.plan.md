## 2. 目標與業務背景

**痛點：** 鄭翔祐在 4/16 確定有黃品皓的課，但老師與主任在智慧排課（SmartCalendar）上完全看不到該堂，導致無法點名、填評量、確認上課狀況。

**業務價值：** 日曆準確性是老師日常作業的基礎，缺課堂顯示會連帶影響出缺勤補登、學習評量入口。

**成功指標：** 4/16 該課堂在 SmartCalendar 週/日視圖中正常出現，角標、點名入口可正常使用。

## 5. 根因分析（代替 User Stories）

### 主要根因：classSessionsApi 無日期範圍

`SmartCalendar.vue` 第 1985–1990 行呼叫：

```1985:1990:frontend/src/pages/SmartCalendar.vue
const { byClass } = await fetchClassSessions({
  token,
  branchId: isTeacher.value ? 0 : branchId,
  studentClassIds: ids,
  perPage: 2000,
});
```

**未傳 `start` / `end`**。後端 `ClassSessionController::index` 以 `SessionDate ASC` 排序並分頁（每頁上限 2000）；對於開課已久、累積大量 ClassSession 的課程，2000 筆容量耗盡在歷史舊堂，4/16 等近期堂次完全不出現在第一頁。

對照：同頁已有正確做法：schedules 呼叫使用 `schedRangeStart/End`（第 1923–1926 行）；`TeacherHomePage.vue` 也正確傳 `start`/`end`。

### 次要根因（需排查但較不可能）

- ClassSession for 4/16 status 為 `cancelled` → 日期被排除
- 課程 `branch_id` 與目前選取分校不符

## 6. 功能需求（FR）

- **FR-001**：`SmartCalendar.vue` 的 `fetchClassSessions` 呼叫必須傳入 `start` = `schedStart`（與 schedules 窗口一致）、`end` = `schedEnd`，使後端只回傳顯示月份 ±2 個月內的 ClassSession。
- **FR-002**：`CourseManagement.vue` 與 `LearningRecordsPage.vue` 若呼叫 `fetchClassSessions` 時未傳日期範圍，須補上對應的日期窗口。
- **FR-003**：修復後，鄭翔祐 4/16 課堂需在 SmartCalendar 週視圖中正確出現（前提：該 ClassSession 存在且非 `cancelled`）。

---

## 7. 非功能需求（NFR）

- 加上日期過濾後，API 請求資料量降低，回應時間改善
- `per_page=2000` 保持不變，日期窗口 (≈4 個月) 已足夠
