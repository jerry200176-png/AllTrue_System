# 兼職薪資人數加成公式修正（修訂版）

## 根本設計變更

| | 舊設計 | 新設計 |
|---|---|---|
| **加成來源** | ClassType（合約）| 實際同時段 LR 數（實際在場學生） |
| **一對二合約、只來 1 人** | +50/h | **+0** |
| **一對二合約、兩人都來** | +50/h | **+100/h**（2 LR 重疊，各 +50） |
| **一對三合約、三人都來** | +100/h | **+150/h**（3 LR 重疊，各 +50） |

> 核心原則：**每一個實際在場學生貢獻 +50/h，但一對一不加**。判斷方式 = 同一老師、同一天、同時段重疊的 LR 筆數。

## 1. 後端：FinanceController.php 兩處改動

### 改動 A — `buildSessionRow()`（約 L1009）

```php
// 舊：依 ClassType 固定加成
$headcountBonus = ($studentCount - 1) * $bonus;

// 新：恆 0，加成全部來自 concurrencyBonus
$headcountBonus = 0;
```

`effective_rate` 和 `session_salary` 計算不變（headcountBonus 仍作為欄位回傳，只是值為 0）。

### 改動 B — `buildConcurrencyBonusMap()`（約 L1050）

```php
// 舊：student_count 依 ClassType（one_on_two=2, one_on_three=3）
$studentCount = match ($sc->ClassType ?? 'one_on_one') {
    'one_on_two'   => 2,
    'one_on_three' => 3,
    default        => 1,
};

// 新：每筆 LR 代表 1 個實際學生，一律為 1
$studentCount = 1;
```

重疊觸發條件（`lrCountInSeg >= 2`）和加給公式（`bonusPerStudent × student_count × dt`）不變。

## 2. 測試更新（ParttimePayrollTest.php，3 個斷言）

| 測試方法 | 舊值 | 新值 | 計算說明 |
|---------|------|------|---------|
| `test_golden_one_on_two_junior_rate` | 800 | **700** | 350×2h，單筆 LR 無重疊，headcount=0，concurrency=0 |
| `test_golden_one_on_three_elementary_rate` | 800 | **600** | 300×2h，同上 |
| `test_concurrency_bonus_mixed_class_types` | 1850 | **1700** | A(one_on_two)基薪 800+50=850，B 基薪 800+50=850 |

`test_concurrency_bonus_mixed_class_types` 原本 A 的 concurrencyBonus 是 `50×2×1h=100`，改後為 `50×1×1h=50`，所以 A 薪資 1000→850，B 不變 850，合計 1850→1700。

**其他並堂測試**（兩個或三個 one_on_one 重疊）：student_count 本來就是 1，邏輯不變，測試無需修改。

`PayrollRulesTest.php` 與 `PayrollTeacherOverrideTest.php` 全部使用 one_on_one，不受影響。

## 4. QA 新增測試

### 新測試 A — 一對二兩個學生都來（happy path）

```
老師 T，同一天 10:00-12:00
LR A：StudentClass(one_on_two, GradeID=7)，同時段
LR B：StudentClass(one_on_two, GradeID=7)，同時段
期望：
  - 每筆 LR：base 350×2=700 + concurrency 50×1×2=100 = 800
  - teacher total_salary = 1600
```

### 新測試 B — 分校規則 headcount_bonus 不再影響計算（regression proof）

```
設分校規則 headcount_bonus=200
老師 T，one_on_two 單筆 LR，10:00-12:00（無其他重疊 LR）
期望：total_salary = 350×2 = 700（headcount_bonus=200 被忽略，無 concurrency bonus）
```
