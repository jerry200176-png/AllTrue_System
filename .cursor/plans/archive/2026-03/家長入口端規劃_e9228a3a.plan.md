# 家長入口端規劃

## 現況摘要

- **前端**：Vue 3，[ParentPortal.vue](frontend/src/pages/ParentPortal.vue) 提供家長入口；可透過 `#/parent` 或 `?parent=1` 獨立開啟。登入方式：學生代號+手機、或 LINE 登入（LIFF）。登入後可看儀表板：剩餘堂數、繳費通知、近期課程、課程與堂數、已核准學習評量、出缺勤紀錄、LINE 綁定說明。
- **後端**：Laravel，[ParentPortalController](backend/app/Http/Controllers/ParentPortalController.php) 提供 `parent/login`、`parent/login-line`、`parent/dashboard`、請假、繳費通知文案。家長身分以 [ParentSession](backend/app/Models/ParentSession.php) token 辨識；學生與 LINE 綁定存於 [Student](backend/app/Models/Student.php) 的 `LineID`。
- **LINE**：[LineWebhookController](backend/app/Http/Controllers/LineWebhookController.php) 處理官方帳號訊息與「綁定 學生代號 手機號碼」；LIFF 網址用於選單連結，從 LINE 內開啟時若已綁定會自動 `loginWithLine` 免再輸入帳密。
- **學習評量**：[LearningRecord](backend/app/Models/LearningRecord.php) 已有 `QuizScore`、`Progress`、`Comment` 等欄位；考試／測驗分數納入評量內容或 QuizScore，不另做獨立考試模組。家長端 dashboard 已回傳完整 learning_records。

---

## 一、功能範圍與資料流

### 1.1 家長可見內容（維持／微調）

- **剩餘堂數**：資料來源 StudentClass.RemainingSessions（堂數制加總）；總計 + 各課程明細。
- **學習評量表**：LearningRecord（Status=approved）；含授課進度、學習建議；測驗分數可寫在 QuizScore 或 Progress/Comment。
- **出缺勤紀錄**：StudentSignIn；到／離班紀錄。
- **繳費通知**：依課程剩餘堂數與 Paid 標記；提醒加購或繳費。
- **近期課程**：ClassSession；可請假。
- **LINE 綁定狀態**：Student.LineID；已綁定則從 LINE 進入免登入。

### 1.2 登入與 LINE 綁定流程

1. **一般登入**：學生代號 + 手機 → `POST parent/login` → 回傳 token，存 localStorage。
2. **綁定 LINE**：家長在官方帳號輸入「綁定 學生代號 手機號碼」→ Webhook 驗證學生與手機後寫入 `Student.LineID`。
3. **LINE 登入／免登入**：從 LINE 官方帳號選單點入 LIFF → 若 `liff.isLoggedIn() && !token` 則自動 `loginWithLine()`（用 LINE userId 換 token）。綁定後從 LINE 進入即不需再輸入帳密。

### 1.3 考試分數不另做模組

- 老師在填寫學習評量時將測驗／考試分數寫入 **QuizScore** 或 **Progress／Comment** 文字。
- 家長端僅需顯示既有學習評量；可選在表格多一欄「測驗分數」顯示 `QuizScore`。

## 二、前端調整建議

### 2.1 學習評量表格（可選）

- **位置**：[ParentPortal.vue](frontend/src/pages/ParentPortal.vue)「已核准學習評量」區塊。
- **調整**：若希望測驗分數更醒目，可加一欄「測驗分數」顯示 `record.QuizScore`（有值才顯示或顯示「—」）。其餘欄位維持：日期、科目、授課老師、授課進度、學習建議。

### 2.2 說明文案

- 使用說明維持：學生代號+手機登入、LINE 綁定後從 LINE 進入可查看、登入後可查看剩餘堂數／學習評量／出缺勤／繳費通知；**學習評量內容可包含測驗或考試分數**（不需單獨寫「考試分數」功能）。

---

## 三、後端與設定（無須改動即可運作）

- **parent/dashboard** 已回傳完整 `learning_records`（含 QuizScore、Progress、Comment 等），無需改 API。
- **LINE**：確認 `config/services.line`（channel_secret、channel_access_token、liff_id）與前端 `VITE_LIFF_ID` 已設；官方帳號選單連結設為 `https://liff.line.me/{liffId}`。
- **老師端**：若學習評量表單有 QuizScore 欄位，老師即可填寫；若無，可鼓勵寫在 Progress 或 Comment。
