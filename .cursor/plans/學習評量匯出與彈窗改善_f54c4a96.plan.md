---

## 2. 目標與業務背景

**痛點：**
- 老師填好學習評量後，需截圖傳給主任或行政老師，再由官方帳號轉傳家長。
- 現有「檢視評量」彈窗內容過長，一張截圖無法涵蓋全部資訊，導致老師仍須另外手動填一次紙本日誌。
- 姓名顯示為「學生 #666」代號，截圖後無法讓家長辨識。

**業務價值：**
- 老師填完即可一鍵下載 PNG，省去手動截圖拼接與重填流程。
- 家長收到圖片有完整姓名，具識別性。

**成功指標：**
- 老師在「檢視評量」modal 內可一鍵下載單筆 PNG，下載時間 < 3 秒。
- 下載圖中學生姓名正確顯示，不出現「學生 #xxx」。
- 所有學習評量相關彈窗及「回報系統問題」可點擊背景關閉。

## 3. 範圍

**In Scope：**
- 單筆評量一鍵下載 PNG（老師「檢視評量」readonly 模式）

## 5. User Stories

**US-01** As a 任課老師, I want 填完學習評量後一鍵下載 PNG 圖檔, so that 可直接傳給主任轉發家長，不需截圖或重填。
> Acceptance Criteria：
> - [ ] 在「檢視評量」readonly 模式下，modal header 有「下載圖檔」按鈕
> - [ ] 點擊後自動下載 PNG，檔名格式：`評量_${學生姓名}_${上課日期}.png`
> - [ ] 下載中顯示 loading 狀態，完成後按鈕恢復正常
> - [ ] 圖中學生姓名顯示正確，非「學生 #xxx」

**US-02** As a 任課老師, I want 檢視評量時看到學生真實姓名, so that 截圖或下載的圖片家長可辨識。
> Acceptance Criteria：
> - [ ] 檢視評量 modal 學生欄位顯示真實姓名（非「學生 #666」）
> - [ ] 即使學生不在目前 `studentList` 快取，仍優先用 record 本身的 `student_name`

**US-03** As a 任課老師/主任, I want 點擊彈窗背景就能關閉, so that 操作流程更順暢，不需找關閉按鈕。
> Acceptance Criteria：
> - [ ] 學習評量所有彈窗（主表單、一鍵補登、更換老師、匯出）均支援點背景關閉
> - [ ] 「回報系統問題」彈窗支援點背景關閉
> - [ ] 點擊背景時有 `cursor: pointer` 提示

**`BugReportLauncher.vue` — 「回報系統問題」modal：**

| 面向 | 要求 |
|---|---|
