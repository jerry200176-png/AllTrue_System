# AllTrue External Review

## 1. Purpose

找出真正值得外問的問題；用完整 Funnel 證據驗證機制價值。  
**沒有值得問就不要問。**

權威：[`docs/GUIDE_EXTERNAL_REVIEW_LOOP.md`](../../../docs/GUIDE_EXTERNAL_REVIEW_LOOP.md)

## 2. When to activate

- COUNTER valuable ≥ 5  
- 使用者要求  
- Bootstrap  

## 3. Required workflow

1. INDEX → GUIDE  
2. 掃訊號 + Registry reopen  
3. Candidate → Research → **Reject 或 Draft**（記完整 Funnel）  
4. 零 Draft → 原因碼；連續兩輪零 → [`META_REVIEW_TEMPLATE.md`](../../../docs/reviews/external-review/META_REVIEW_TEMPLATE.md)  
5. Round log：Funnel + Blind Spot + 機制效益；同步 SCORECARD  
6. Round 5 → [`RETROSPECTIVE_TEMPLATE.md`](../../../docs/reviews/external-review/RETROSPECTIVE_TEMPLATE.md)  
7. COUNTER 更新 → 繼續開發  

## 4. Forbidden

- ⛔ 為輪次／KPI／Meta Review 硬凑 Draft  
- ⛔ Funnel 省略 Reject  
- ⛔ 無新訊號空轉 Round  
- ⛔ Round 5 Retrospective 前加 Journal／KB  
- ⛔ 把 Round 5 目標窄化成「要不要加模組」  

## 5. Exit

- [ ] Funnel 七段已記  
- [ ] 連續零 Draft≥2 → Meta Review  
- [ ] Round 5 → Retrospective  
- [ ] SCORECARD 同步
